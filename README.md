# TiendaOnline

Plataforma web de comercio electrónico (E-commerce) desarrollada con Node.js, Express y renderizado de estilos con SASS y Bootstrap 5.

## Requisitos previos

- [Node.js](https://nodejs.org/) (versión 18 o superior)
- `npm` (gestor de paquetes incluido con Node.js)

## Instalación

1. Clona el repositorio o descarga el código fuente:
   ```bash
   git clone <URL_DEL_REPOSITORIO>
   cd tiendaOnline
   ```
