# TiendaOnline

Plataforma web de comercio electrónico (E-commerce) desarrollada con Node.js, Express, MongoDB, SASS y Bootstrap 5.

## Requisitos previos

- [Node.js](https://nodejs.org/) (versión **20.19.0** o superior).
- `npm` (gestor de paquetes incluido con Node.js).

## Instalación

1. Clona el repositorio en tu computadora:
   ```bash
   git clone [https://github.com/edwardcaicedo/tiendaOnline.git](https://github.com/edwardcaicedo/tiendaOnline.git)
   cd tiendaOnline
   ```
